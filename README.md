A lightweight server-driven table for Laravel using blade and HTMX

## Installation

You can install the package via Composer:

```bash
composer require ahmaruff/laravel-htmx-table
```

You may publish all of the package's resources at once:

```bash
php artisan vendor:publish --tag="laravel-htmx-table"
```

Or, you may publish each resource individually:

### Publishing the Configuration File

```bash
php artisan vendor:publish --tag="laravel-htmx-table-config"
```

### Publishing the Views

```bash
php artisan vendor:publish --tag="laravel-htmx-table-views"
```

### Publishing the Public Assets

```bash
php artisan vendor:publish --tag="laravel-htmx-table-assets"
```
